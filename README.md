# My Learning Repository

> 研究生学习记录：课程笔记、论文阅读、练手项目与每日学习日志。

## 关于我

- 身份：即将入学的研究生（研究方向：计算机视觉 具身智能）
- 目标：把日常学习沉淀成可追溯、可回顾的记录，同时练习用 Git/GitHub 做版本管理。

## 目录结构

```
my-learning/
├── README.md        # 本文件：仓库总览
├── courses/         # 课程笔记（按课程建子文件夹）
├── papers/         # 论文阅读笔记（按年份/主题分类）
├── projects/       # 练手项目
├── daily/          # 每日/每周学习日志
└── notes/          # 环境搭建、工具使用等通用笔记
```

## 环境

- 系统：Windows
- Python 发行版：Anaconda（conda 26.5.3 / Python 3.14.6）
- 深度学习框架：PyTorch 2.14.1 + CUDA 12.6（GPU: NVIDIA RTX 4060 Laptop）

## 如何使用这个仓库

每天学习后，在对应目录新建一个 `.md` 笔记或保存 Jupyter Notebook，然后用 GitHub Desktop：
**写内容 → Commit（写一句话说明）→ Push（推送到云端）**。
