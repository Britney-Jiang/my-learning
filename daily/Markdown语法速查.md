# Markdown 语法速查（写笔记够用版）

> 原则：先写大白话，再用符号"标注"格式。字体、字号、颜色不用管，GitHub 自动排版。

## 1. 标题：行首加 #（# 越多，级别越小）

写的时候：
```
# 大标题
## 小标题
### 更小的标题
```
显示成：一级标题最大最粗，往下依次变小。

## 2. 列表：行首加 `- `（短横杠+空格）

写的时候：
```
- 第一点
- 第二点
- 第三点
```
显示成一个个圆点。有序列表用 `1. ` `2. `。

## 3. 加粗：文字两边包两个星号

写的时候：`**重点内容**`
显示成：**重点内容**

## 4. 代码：单行用反引号包起来，整段用三个反引号

单行：`` `print(a)` `` → 显示成等宽的代码样式
整段：
````
```python
import numpy as np
a = np.array([1,2,3])
```
````

## 5. 分段：两段之间空一行

不空行 = 同一段；空一行 = 另起一段。

## 写笔记的偷懒建议

- 记不住符号没关系，**先把话用纯文本写出来**，能表达清楚最重要，格式以后再补。
- 不需要选字体、颜色、居中、调字号，这些 Markdown 笔记里基本用不到。
- 拿不准就照着已有笔记（如 01-Lesson1.1）的样子模仿。
